# Installation, scoring, and worksets

Python 3.11–3.14 is supported. Install from the repository with `python -m pip
install .`, or use `python -m pip install -e '.[dev]'` for development. A PyPI
release has not yet been made as part of this migration.

After installation, `citsci-score --help` and `python -m citsci_analysis --help`
expose the same commands. The source-tree `PYTHONPATH=src` invocation remains
available. The guide below retains the original scientific definitions, CLI
examples, schemas, workset conventions, and historical comparison results.
